# Kantara – Madana Manamohini 🎶

This is a **cinematic animated lyric page** built using HTML, CSS, and JavaScript.  
It displays the *Madana Manamohini* song lyrics line-by-line with glowing Kannada text and a beautiful forest background.

## 🌟 Features
- Animated Kannada lyrics (line-by-line)
- Cinematic forest background with slow zoom
- Works with any MP3 song (just replace the file in `assets/audio/`)
- Fully responsive and runs offline
